# We Studio Enterprise — v2.1.1

## رفع اختلال رابط تک‌صفحه‌ای
- تمام Viewها اکنون واقعاً مستقل هستند و فقط View فعال نمایش داده می‌شود.
- ناوبری با Hash داخلی (`#dashboard`, `#brand-dna`, ...) پایدار شده است.
- دکمه‌های ناوبری `aria-current` دریافت می‌کنند.
- اجرای inline JavaScript از HTML حذف شد.
- متغیرهای قدیمی CSS در رندر تاریخچه اصلاح شدند.
- عنوان بخش بازبینی به فارسی اصلاح شد.
- نسخه افزونه به 2.1.1 ارتقا یافت.

## ساختار
افزونه Chrome Manifest V3 است و با `chrome.storage.local` داده‌ها را نگهداری می‌کند.


## نسخه 2.2.0 — شروع هوشمند
- بخش «شروع» قبل از هویت برند اضافه شد.
- فقط در صورت ثبت API Key سؤال‌های مشاوره‌ای نمایش داده می‌شوند.
- نام کاربر به‌صورت اجباری پرسیده می‌شود.
- ۹ سؤال ساده مرحله‌ای برای شناخت کاربر و برند اضافه شد.
- پاسخ‌ها در حافظه محلی ذخیره می‌شوند.
- پس از تکمیل همه پاسخ‌ها، AI پاسخ‌ها را تحلیل و Brand DNA را تکمیل می‌کند.
- قبل از اعمال تحلیل AI از Brand DNA قبلی Snapshot گرفته می‌شود.
- پس از ساخت هویت، کاربر مستقیماً به بخش هویت برند هدایت می‌شود.

## نسخه 2.3.0 — مشاور شروع هوشمند
- برای تمام پرسش‌های هویت برند، گزینه‌های آماده و استاندارد ارائه می‌شود.
- همیشه امکان تایپ پاسخ شخصی وجود دارد.
- تحلیل نهایی مشاوره با مدل اقتصادی `gpt-4o-mini` انجام می‌شود تا هزینه اجرای مسیر شروع پایین بماند.
- راهنمای مرحله‌ای در تمام سؤال‌ها نمایش داده می‌شود.
- نام کاربر همچنان سؤال اول و الزامی است.
- تا زمانی که API متصل نباشد، سؤال‌های مشاوره نمایش داده نمی‌شوند.


## نسخه 2.4.0
- راهنمای زنده برای گزینه‌های Instagram Engine اضافه شد.
- فهرست مدل‌های AI از endpoint استاندارد `/models` سرویس متصل دریافت و برای مدل اصلی، مشاوره شروع و Transcription قابل انتخاب شد.
- همه موتورهای تولید محتوا از Brand DNA فعال تغذیه می‌شوند و بعد از تولید یک کنترل یکپارچگی واژگانی نیز اجرا می‌شود.
- مدل‌ها بر اساس Gateway انتخاب می‌شوند تا فقط مدل‌های واقعاً ارائه‌شده توسط سرویس قابل استفاده باشند.


## نسخه 2.7.0
- حالت Dark Mode حرفه‌ای با ذخیره انتخاب کاربر
- سازگار با RTL و Vazirmatn
- پشتیبانی از popup راهنما در حالت تاریک


## نسخه 2.8.4 — پاک‌سازی داشبورد و Dark Mode
- بخش‌های «نبض بازار»، «تاریخ/تقویم»، «معرفی/پیشنهاد فیلم»، «آب‌وهوا» و «جستجوی سریع» از رابط کاربری داشبورد حذف شدند.
- حالت Dark Mode در هویت برند، شروع و بازبینی به‌صورت کامل اعمال و یکپارچه شد.
- ساختار داشبورد، فرم‌ها، کارت‌ها و چک‌لیست بازبینی بدون تغییر در قابلیت‌های اصلی حفظ شده‌اند.
- نسخه Manifest به 2.8.4 ارتقا یافت.
- نسخه 3.0.7: کارت‌های چک‌لیست بازبینی کوچک‌تر و متراکم‌تر شدند؛ Checkbox در سمت چپ کارت قرار گرفت و فضای متن از کنترل جدا شد.

- نسخه 3.0.9: ساختار چک‌لیست بازبینی به Grid صریح تغییر کرد تا Checkbox به‌صورت فیزیکی در سمت چپ کارت قرار بگیرد و متن هیچ‌گاه زیر آن قرار نگیرد.
